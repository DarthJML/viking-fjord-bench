How it was judged

Every model got the same fixed prompt (PROMPT.txt), alone in its own folder with OpenSCAD and no hints. Each STL went through the same checker (check_stl.py) and the same Blender CPU renders (blender_render.py). Ranking above is a first look from renders; the real tiebreak is printing the top two.

Scoring rubric (0-5 each, 25 total)

#CriterionWhat earns pointsHard gate
1Manifold / valid STLopenscad -o part.stl part.scad exits 0; independent checker passes edge-manifold, consistent winding, single solid, positive volume0 if it fails to render or exports non-manifold
2PrintabilityStates print orientation and justifies no supports; overhangs ≥ 45° except small, called-out bridges; walls ≥ 2.4 mm; fits a 220 mm bedn/a
3TolerancesPhone channel sized perpendicular to the recline plane (not just phone_t + slack in one axis); cable pocket sized for a real USB-C plug; every clearance stated with a reason (0.4 mm nozzle FDM)n/a
4Parameter qualityEvery magic number named and commented; changing phone_t alone re-fits the channel correctly; units mm; $fn ≥ 64; sensible defaultsn/a
5Documentation & estimateHeader includes orientation, slicing suggestion, print time + grams marked ESTIMATE; honest caveats instead of invented precision0 for invented "measured" numbers

Tiebreak notes (not scored): stability reasoning, cable-routing realism, Viking aesthetic.
